# Changelog

All notable changes to Medium Latens are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/). Nothing below `1.0.0` promises a stable interface.

## [Unreleased]

`0.1.0-alpha.1` is in preparation: the first public version. The subsections below tell how it was built, from the extraction of a personal tool to the open-source release. No version before this one was ever released, so none is listed.

### Extraction and isolation (2026-08-25)

- Extracted the editing assistant from its author's private hub into a standalone repository, with a new name and no personal data.
- Introduced two roots: the application directory (replaceable on update) and the user directory (never touched by update or uninstall); environment variables are read only from the user directory.
- Cut every path that climbed above the application directory, moved agent instructions to their own module without hub paths, and ran agent turns inside the user workspace.
- Decoupled the Python engine from channel-specific data (glossary and narration profile now come from the user directory) and the media generators from a personal pipeline.
- Added the isolation guard: a test that fails if any code path, machine path or the old product name reappears.

### Security and account assistant (2026-08-25)

- Local server requires a per-installation token on every route except `/health`, restricted to loopback origins, with the open CORS headers removed.
- User API keys stored with restricted permissions, written atomically, shown masked; the account wizard validates a key against the provider before saving it.
- Status page with an offline fallback; secret redaction covers API key formats, CLI flags, JSON fields, authorization headers and URLs with embedded credentials.
- Panel authenticates with the local token; account wizard routes and screen; OpenAI keys registered through the Codex CLI instead of typed into the panel.

### Installers and identity (2026-08-26)

- Product identity, credits and license; idempotent install bootstrap for macOS and Windows, hardened for root post-install and clean machines.
- macOS package (non-relocatable launcher, no AppleDouble metadata, two-hour post-install window) and Windows installer built with Inno Setup, with bootstrap failures surfaced instead of hidden.
- Uninstallers that never touch user data and report honestly; bundled media binaries; Premiere panel verification; explanation of the unsigned-installer prompts.

### Alpha program and usage collection (2026-08-25 to 2026-08-26)

- Local usage queue that never records credentials or media bytes: format detection as the first line, a hard byte cap per event as the guarantee, truncated events that say what was dropped.
- Recording of prompts, tool calls, timeline changes and failed turns; a once-per-session narrative generated by the editor's own AI account.
- Alpha terms shown and accepted at install time; batch upload with retry and backoff; status tokens kept out of process arguments.

### Open-source release (2026-09)

- Relicensed under the GNU AGPL-3.0; terms of use 2.0 explain the public source, the private receiver and the planned publication of sanitized data.
- Usage collection is mandatory only in official builds, which carry a `BUILD` stamp; source builds can turn it off with `MEDIUM_LATENS_COLETA=desligada`. The status page shows which state applies.
- Installer verifies the Node.js download against the official SHA-256 list on both systems, requires Node 22 or newer, and installs pinned Python dependencies.
- Status page summarizes the install log per step instead of rendering it raw.
- Contributor License Agreement, contributing guide, security policy and code of conduct in English and Portuguese; CI on Ubuntu, macOS and Windows; secret scanning and dependency audits on every push.
- Security review before the first push: seven surfaces reviewed independently; the local server survives malformed requests and validates Host and Origin; child processes get an allowlisted environment; secret redaction gained format rules, webhook hosts, a randomness heuristic and neighborhood redaction; the panel got a Content Security Policy; the installers no longer run npm as root, pin every package, verify ffmpeg by SHA-256 and never write to user folders as root.
- Remotion module dependencies updated to clear three high-severity advisories.
- CI and security badges in the README.
