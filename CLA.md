## Como assinar

Comente no seu pull request, com esta frase exata: `I have read the CLA Document and I hereby sign the CLA`. O workflow do repositório registra a assinatura (seu nome de usuário do GitHub, o id numérico da conta, a data e o número do PR) no arquivo `signatures/v1.json` da branch `cla-signatures` deste mesmo repositório, e marca o check `CLA` do PR como aprovado.
